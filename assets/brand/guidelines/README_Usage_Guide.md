# MELD by IDEO — Logo Kit

## Included
- Editable SVG and high-resolution transparent PNG exports.
- Light and dark theme lockups: horizontal, stacked, symbol-only and wordmark-only.
- Monochrome black and white versions for single-ink use.
- Light/dark overview boards.

## Identity concept
The three stacked planes represent the foundations, components and patterns that come together in a cohesive design system. The wordmark is paired with the endorsement “by IDEO”.

## Colour direction
The symbol uses a cool-to-warm gradient inspired by the supplied IDEO identity reference: pale cyan, blue, indigo, violet, magenta and soft pink. Text is near-black on light backgrounds and warm white on dark backgrounds.

## Usage
- Use `horizontal` for website headers, documentation headers and presentations.
- Use `stacked` where a centered or square composition is needed.
- Use `symbol` for favicon/app icon/avatar placements.
- Use `wordmark` when the symbol is already present nearby.
- Use monochrome artwork for constrained print, embossing or single-colour applications.
- Keep clear space around the logo at least equal to the height of the “by IDEO” line. Do not stretch, rotate, recolour individual layers or add effects.
- On dark surfaces, use the dark theme export; on light surfaces, use the light theme export.

## Typography
The SVG wordmark uses a bold geometric sans-serif stack led by Space Grotesk, with Noto Sans/Arial fallbacks. For exact consistency in a production brand system, convert text to outlines in your vector editor after selecting the approved brand font.

## Production note
These are clean, editable vector constructions based on the approved stacked-layer direction and the supplied IDEO colour reference. The gradients are a considered approximation of the reference image rather than extracted official brand colour values. Confirm final colour values and typography against IDEO brand standards before public release.
